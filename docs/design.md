# 设计适配

本站设计以本文为准；需追溯设计依据时再读 [原始参考](../DESIGN.md)。六个基础色映射到 Tailwind v4 的 @theme；全局 UI 和正文样式属于 shared，功能组件使用局部样式。

只提供深色主题，沿用六个基础色。Inter 和 Geist Mono 的 WOFF2 随站点自托管；中文使用系统字体，等宽字体用于代码。内容左对齐，容器最大 1280px，桌面两侧至少留白 32px；导航、搜索表单和页脚随容器伸展。页面标题桌面 28px、手机 24px，二级标题 22px。正文约 18px、手机 17px，1.9 行高和 720px 宽度；搜索结果摘要同样限制为 720px，手机两侧留白 20px。长代码和表格在各自区域内滚动。

首页展示圆形头像、一句随访客本地时间变化的问候语（桌面 22px、手机 20px）与社交图标，项目与文章通过导航进入。通用 UI 图标使用 Lucide 的 Astro 组件，线宽 1.5px，菜单与搜索 18px、RSS 16px、社交链接 22px；GitHub、Bilibili 品牌标志使用 Simple Icons。邮箱使用信封，未指定图标的链接使用地球；按需渲染静态 SVG，纯图标链接保留可访问名称、悬停提示与 44px 点击区域，有文字的图标对辅助技术隐藏。文章、项目统一为单栏文字列表，展示标题、摘要、文章日期和必要示例标记；标签与技术栈放在详情页。删除装饰图、假封面、重复操作、固定口号和模板指导文案，空经历不渲染；搜索和评论保留必要状态与重试入口。页脚仅保留 RSS 与年份。

细边框只区分内容结构，无阴影或装饰渐变。仅首页提供一次约 1.2 秒的开场：圆形头像淡入、下方细线完成、深色遮罩淡出，不增加逐区块进场或循环动画。细线表达固定时长的欢迎动效，不代表资源加载进度，不显示百分比或等待网络；页面在遮罩下正常展示，点击或按键立即跳过，不锁滚动或焦点。使用 sessionStorage 标记当前标签页已播放，站内返回和刷新不重复；没有头像、禁用 JavaScript、存储不可用、后台首次打开或开启减少动态效果时直接展示页面。移动端控件保留 44px 点击区域，所有交互提供焦点样式。布局、字体、间距与视觉效果由人工验收。

浏览器标签页隐藏时标题改为“先睡一会儿…”，重新可见时显示“欢迎回来”，1.6 秒后恢复原页面标题。快速反复切换时取消旧计时；离开页面清理计时并恢复标题，浏览器前进后退缓存恢复后保留正确的页面标题。

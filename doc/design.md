# 设计适配

DESIGN.md 是原始参考，保留不改。六个基础色映射到 Tailwind v4 的 @theme；全局 UI 和正文样式属于 shared，功能组件使用局部样式。

只提供深色主题。大标题以尺寸和字距建立层次，Inter 和 Geist Mono 的 WOFF2 随站点自托管；中文使用系统字体。正文约 18px、1.9 行高和 720px 宽度。长代码和表格在各自区域内滚动。

首页以作者姓名作为视觉中心，项目可使用不同大小的展示区域，文章保持列表。细边框区分结构，胶囊承载交互，无阴影、装饰渐变或自动入场动画。移动端保留 44px 点击区域，所有交互提供焦点样式，尊重减少动态效果偏好。

# 设计适配

本站设计以本文为准；需追溯设计依据时再读 [原始参考](../DESIGN.md)。六个基础色映射到 Tailwind v4 的 @theme；全局 UI 和正文样式属于 shared，功能组件使用局部样式。

只提供深色主题，沿用六个基础色。Inter 和 Geist Mono 的 WOFF2 随站点自托管；中文使用系统字体，等宽字体用于代码。内容左对齐，容器最大 960px；页面标题桌面 28px、手机 24px，二级标题 22px。正文约 18px、手机 17px，1.9 行高和 720px 宽度；手机两侧留白 20px。长代码和表格在各自区域内滚动。

首页只展示简短个人介绍，项目与文章通过导航进入。文章、项目统一为单栏文字列表，展示标题、摘要、文章日期和必要示例标记；标签与技术栈放在详情页。删除装饰图、假封面、重复操作、固定口号和模板指导文案，空经历不渲染；搜索和评论保留必要状态与重试入口。页脚仅保留 RSS 与年份。

细边框只区分内容结构，无阴影、装饰渐变或自动入场动画。移动端控件保留 44px 点击区域，所有交互提供焦点样式，尊重减少动态效果偏好。布局、字体、间距与视觉效果由人工验收。
